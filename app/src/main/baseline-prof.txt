# ART baseline profile.
#
# AGP compiles this file into assets/dexopt/baseline.prof at build time, and
# androidx.profileinstaller copies it into place on first run. ART then
# AOT-compiles the matched code instead of discovering it at runtime, which is
# where the cold-start and first-frame jank in a Compose + ExoPlayer app comes
# from.
#
# Rule syntax: [FLAGS][CLASS_DESCRIPTOR]->[METHOD_SIGNATURE]
#   H = hot (called often)   S = startup   P = post-startup
# A rule with no `->` is a *class* rule: the class is pre-allocated and loaded
# eagerly, skipping class loading on the critical path.
#
# `**` wildcards are supported in both class descriptors and method signatures,
# and are used throughout so a rule cannot start failing when a class is renamed
# or moved. Nothing here names a specific method, so a refactor cannot invalidate
# a rule.
#
# ---------------------------------------------------------------------------
# S = on the startup critical path, before the first frame is drawn
# ---------------------------------------------------------------------------
